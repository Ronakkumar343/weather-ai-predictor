# 🌦️ Weather AI Predictor

An AI-powered weather predictor that forecasts conditions using **real-time weather data** and **machine learning** — built with React + TypeScript.

> **Status: 🚧 in development.** This is the project scaffold — the first commit. Code lands here in stages; the list below is the build plan.

## 🎯 What it will do

- Pull **real-time weather data** for any location
- Run the data through an **ML model** to forecast upcoming conditions
- Present forecasts in a clean, fast **React + TypeScript** interface

## 🛠️ Planned stack

- **Frontend:** React + TypeScript
- **ML:** a Python-trained forecasting model
- **Data:** real-time weather APIs
